# Weather-App
A responsive Weather App built using HTML, CSS, JavaScript, and Weather API integration. It provides real-time weather information, including temperature, humidity, wind speed, and weather conditions for any city worldwide. The application features a clean user interface, fast performance, and an enhanced user experience across all devices.

Tech Stack: HTML • CSS • JavaScript • Weather API
Features: Real-time Weather • City Search • Responsive Design • API Integration • Dynamic UI
